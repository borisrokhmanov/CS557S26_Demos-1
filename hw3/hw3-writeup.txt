Boris Rokhmanov CS557 HW3 Writeup

I ran this code on a docker container running Ubuntu 22.04 using AMD64. The actual container ran on my MacBook Pro using the Apple M2 Pro CPU.
I also ran the following commands in the docker container to download Intel MKL:
wget https://registrationcenter-download.intel.com/akdlm/IRC_NAS/6a17080f-f0de-41b9-b587-52f92512c59a/intel-onemkl-2025.3.1.11_offline.sh
sudo sh ./intel-onemkl-2025.3.1.11_offline.sh -a --silent --cli --eula accept
export CPLUS_INCLUDE_PATH="$CPLUS_INCLUDE_PATH:/opt/intel/oneapi/mkl/2025.3/include/mkl.h"
source /opt/intel/oneapi/setvars.h
I compiled the code using 'g++ -std=c++11 -O3 -fopenmp \
    -I${MKLROOT}/include \
    -L${MKLROOT}/lib/intel64 \
    -Wl,--no-as-needed \
    -lmkl_intel_lp64 \
    -lmkl_gnu_thread \
    -lmkl_core \
    -lgomp \
    -lpthread -lm -ldl \
    *.cpp'

I replaced the InnerProduct(), Copy(), and Norm() calls.
